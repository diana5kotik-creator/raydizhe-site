# What Our Souls Are Made Of — RayDi Zhe

Готовая статическая версия сайта для GitHub Pages: утверждённый дизайн, движение слоёв в глубину, мобильная раскладка, семь фотографий и пять видео.

## Размещение

1. Создайте репозиторий в GitHub. Для GitHub Pages на бесплатном тарифе нужен публичный репозиторий; его содержимое будет доступно всем.
2. Загрузите содержимое этого архива в корень репозитория. Рядом должны лежать `index.html`, `styles-depth.css`, `script-depth.js`, `.nojekyll` и папка `assets`. ZIP-архив сам по себе не является страницей сайта: сначала распакуйте его.
3. Откройте **Settings → Pages → Build and deployment**.
4. Выберите **Source: Deploy from a branch**, свою ветку (обычно `main`) и папку **/(root)**. Нажмите **Save**.
5. После успешной публикации используйте **Visit site** в разделе Pages. Эта ссылка открывает сайт; ссылка на сам репозиторий показывает файлы.

Сайт GitHub Pages будет публичным и не потребует входа в ChatGPT. Подключение домена `raydizhe.com` выполняется отдельно; этот пакет не меняет DNS или настройки домена.

## Просмотр и медиа

- Для просмотра на телефоне откройте опубликованную ссылку в браузере.
- При входе выберите **Enter with sound**. Браузер требует первого взаимодействия для звука; некоторые мобильные браузеры и режимы энергосбережжения могут ограничивать автозапуск. Кнопки Play и Sound остаются доступны.
- В настройке уменьшения движения анимации глубины отключены.
- Картинки, постеры и видео включены в папку `assets`. Шрифты загружаются из Google Fonts; при недоступности используются системные шрифты.
- В текущем HTML сохранён `noindex,nofollow` для предварительного просмотра. Это просьба поисковым системам не индексировать страницу, а не ограничение доступа.
- Установка Node.js или сборка для публикации не нужна.
